# Quiz-Web-App
A simple quiz application built with HTML, CSS, and JavaScript that lets users answer multiple-choice questions and see their final score instantly. The app is hosted live using GitHub Pages and accessible via a public link.

📋 Quiz App – Project Description

This is a web-based Quiz Application developed using HTML, CSS, and JavaScript.
The app allows users to attempt multiple-choice questions, select answers, and view their final score instantly after submission.

The quiz includes features like:

Interactive question navigation

Answer validation (prevents moving forward without selecting an option)

Score calculation at the end of the quiz

Clean and responsive user interface


The project is fully hosted online using GitHub Pages, allowing anyone to access and play the quiz through a shared link without any installation.

🔧 Technologies Used

HTML – Structure of the quiz

CSS – Styling and layout

JavaScript – Logic, score calculation, and interactivity
